## Overview

Bearo is agentic peer-to-peer payments — making it as easy as Venmo for both humans and AI agents to transact autonomously. Send stablecoins to anyone using just their username, no wallet addresses needed, no chain confusion.

Built for a world where AI agents need to pay for services, split costs, and move money just like humans do.

**Status: In Development** — Follow progress on the [24/7 livestream](https://pump.fun/coin/FdFUGJSzJXDCZemQbkBwYs3tZEvixyEc8cZfRqJrpump).

## Key Features

- **Username-Based Payments**: Send USDC/USDT by @username, not wallet addresses
- **Multi-Chain Support**: Solana and EVM chains (Base, Polygon, Ethereum)
- **Agentic Transactions**: API-first design so AI agents can send/receive payments programmatically
- **Email Authentication**: thirdweb user wallets with email verification — no seed phrases
- **Smart Balance Filtering**: View balances by chain and token with persistent preferences
- **Real-Time Tracking**: Transaction status monitoring with blockchain confirmations
- **Mobile-First**: Native iOS app built with React Native + Expo

## Technical Stack

- **Mobile**: React Native, Expo
- **Web3**: thirdweb (wallets, payments, multi-chain)
- **Database**: Supabase (PostgreSQL) with Row Level Security
- **Authentication**: thirdweb email verification + JWT
- **Chains**: Solana, Base, Polygon, Ethereum

## Why Agentic Payments?

AI agents are everywhere — writing code, managing support, running marketing campaigns. But they can't pay for anything. Bearo solves this by giving agents the same payment UX humans get: simple, username-based, multi-chain.

The future isn't just humans paying humans. It's agents paying agents, agents paying humans, and humans paying agents — all through one interface.
