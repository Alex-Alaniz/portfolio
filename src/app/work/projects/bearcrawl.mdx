## Overview

BearCrawl is an AI agent platform designed for organizations to deploy and manage their own autonomous AI agents at scale. With 5 tiers from Cub to Polar Bear, businesses can start small and scale their agent workforce as needed.

## Tiers

| Tier | Agents | Best For |
|------|--------|----------|
| Cub | 1 | Solo founders, testing the waters |
| Black Bear | 3 | Small teams, focused automation |
| Grizzly | 10 | Growing companies, department-level |
| Kodiak | 25 | Enterprise, cross-functional teams |
| Polar Bear | Unlimited | Full AI-native organizations |

## Key Features

- **BYOAuth**: Bring your own API keys and authentication — you control your data
- **Multi-Model**: Support for Claude, GPT, Gemini, and more
- **Agent Templates**: Pre-built agent roles (support, sales, engineering, marketing)
- **Dashboard**: Monitor agent activity, costs, and performance
- **Scaling**: Start with one agent, grow to an entire AI organization

## Technical Stack

- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: PostgreSQL (Neon)
- **Deployment**: Vercel
- **Agent Runtime**: OpenClaw-based agent orchestration

## Why BearCrawl?

We built a 39-agent AI organization for BearifiedCo. BearCrawl packages that same capability for any business. If we can run an entire company with AI agents, your team can automate their most repetitive workflows.
