## Overview

Storefront is a B2B and B2C mobile commerce platform — native SwiftUI apps with a shared Swift Package core. Two apps, one codebase: StoreFront B2B for businesses and StoreFront B2C for consumers.

## Architecture

- **StoreFront B2B**: Business-facing app for inventory, orders, and client management
- **StoreFront B2C**: Consumer-facing app for browsing, purchasing, and tracking
- **StoreFrontCore**: Shared Swift Package with common business logic, networking, and data models

## Key Features

- **Native SwiftUI**: Built entirely in Swift for optimal iOS performance
- **Swift Package Architecture**: Shared core library between B2B and B2C apps
- **Commerce Ready**: Product catalog, cart, checkout, order tracking
- **Business Tools**: Inventory management, analytics, client CRM (B2B)

## Technical Stack

- **Platform**: Native iOS (SwiftUI)
- **Architecture**: Swift Package Manager for shared code
- **Backend**: Supabase (PostgreSQL)
- **Design**: Figma-driven UI with custom design system
